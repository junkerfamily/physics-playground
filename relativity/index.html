Moving clocks run slow.

Each clock ticks when a pulse of light bounces between two mirrors. Light moves at the same speed for everyone, so the moving clock's longer zigzag takes more time to finish each tick.

Why time stretches

From Earth, the ship's light travels a longer diagonal path at the same speed. Each tick must take longer. The stretch factor is 1 / √(1 − v²/c²).

Why the twins differ

While coasting, each twin sees the other's clock running slow. The ship twin is the one who turns around and changes direction, which breaks the tie. This demo treats launch and turnaround as instant.

It affects your phone

GPS satellites lose about 7 microseconds a day from their speed and gain about 45 from weaker gravity. GPS corrects for both, or location errors would quickly build up.
